# WiFi-Radar-CSI-Sensing-Node
ESP32 tabanlı Wi-Fi CSI (Channel State Information) sinyal toplama ve Flask/Socket.IO web arayüzlü temassız insan/cihaz tespit sistemi. Ortamdaki Wi-Fi sinyallerinin genlik ve faz değişimlerini işleyerek kamera veya giyilebilir sensör olmadan insan varlığı, hareket ve solunum tespiti yapar; ağ içi cihaz keşfi ve yerel mesajlaşma sunar
